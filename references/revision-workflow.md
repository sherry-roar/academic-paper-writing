# Revision Workflow

Use this module for practical editing, style-reference work, translation, and explicitly requested reviewer responses. The sequence is structure → logic → expression, with the authorized task determining which layers may change.

## Choose a mode from the request

| Mode | Use when | Behavior |
|---|---|---|
| Direct | The author asks for edits or polishing with sufficient context | Diagnose internally, apply the authorized edits, deliver the result |
| Collaborative | The author asks to proceed step by step or compare substantive options | Present useful decisions at the requested checkpoints |
| Batch | The same operation covers multiple sections | Use one consistent set of constraints and cross-check all edited sections |

Do not turn direct work into a sentence-by-sentence approval procedure. Existing authorization continues to apply. When the author requests language-only editing, identify structural concerns in the accompanying notes instead of silently rebuilding the paper.

## Collect the necessary context

Read the target text and enough surrounding material to preserve the argument. Identify the facts, terminology, numerical values, equations, citations, and author-approved prose that must remain stable.

For a long paper, first recover its main line from the title, abstract, introduction, principal method and evidence, and conclusion. Then inspect the requested sections. Do not read unrelated project material merely because it is available.

Use the requested venue and mode if already supplied. When no venue is supplied, proceed with general English academic writing and leave venue-specific compliance unchecked.

## Structure pass

Identify each section's argumentative role. Check whether the problem, gap, insight, method, strongest result, and conclusion tell the same story. Preserve an effective existing structure.

In collaborative mode, a compact section-function table can make a decision concrete. Do not create extensive planning artifacts for a narrow sentence edit.

## Logic pass

Check sentence functions and dependencies within each paragraph. Distinguish a setup condition, observation, mechanism, comparison, and implication. Resolve unexplained topic changes and ambiguous references.

Apply the launch-presentation principles. Explain the selected design and its advantage rather than narrating the order of attempts. Give experiments a role in the argument and keep operational details in the appropriate records.

## Expression pass

Choose words and syntax that express the established meaning directly. Check technical subjects and actions, grammar, comparisons, tense, reference, terminology, and the house punctuation style.

Remove generic praise, empty effectiveness statements, repetitive caveats, and self-weakening commentary. For less favorable comparisons, use a supported objective or trade-off explanation. Do not change evidence to make a sentence more persuasive.

In collaborative mode, offer a small number of alternatives only when there is a meaningful difference in emphasis or interpretation. In direct mode, apply the best fitting wording and explain material choices briefly.

## Reference-driven style

If the author supplies a model paper or approved passage, read the relevant text. Extract how it introduces the object, develops a causal connection, states the comparison, and moves between sections. Use those functions in the author's context.

Do not infer a paper's style from its title, publisher, or reputation. Do not treat its priority claims, specific sentence structures, or figure colors as official requirements. Avoid copying distinctive wording.

## Translation and optional bilingual explanation

Translate the argument and scientific relation, not just the sentence order. Preserve symbols, values, terminology, negation, conditions, comparison objects, and claim strength.

Use natural English information flow. Do not mechanically transfer fixed chapter introductions or report-style closing sentences from another language into an English paper.

Provide bilingual explanations when requested. Keep the English manuscript text clearly identifiable. If bilingual LaTeX comments or parallel Markdown are requested, use a consistent, unobtrusive format and avoid accidentally inserting explanatory notes into submission text.

## Manuscript files

Edit the authorized file or provide a separate revised artifact as requested. Preserve working LaTeX commands, labels, bibliography keys, equations, and existing file organization. Do not convert a manuscript to another format unnecessarily.

When editing LaTeX, check label and citation references, escaped special characters, math boundaries, and compilation if available and relevant. Compilation verifies document processing, not scientific correctness. Keep generated build products outside protected source material when the project requires it.

Do not modify scientific source code, input data, original reviewer records, or unrelated documents as a consequence of prose editing.

## Requested reviewer responses

Use this part only when response work is requested. Read the actual reviewer comment and the relevant manuscript and evidence. Answer the exact question, identify the supported change, and give the verified manuscript location when available.

Write manuscript additions as positive capability or design statements where the evidence supports them. Do not invent experiments, promise an unapproved study, claim a revision was made when it was not, or dismiss a question without evidence.

Keep an unresolved scientific issue in the working response record until the author supplies the evidence or decision. Do not turn every reviewer concern into an unsolicited weakness paragraph in the paper.

## Delivery

Provide the revised text or saved file, a concise summary of material changes, and any concrete author decisions or evidence gaps in separate working notes. For narrow edits, keep the explanation short.

If requested, include a before/after comparison, section-function table, word count, or change ledger. Do not claim full-paper verification when only an excerpt was available.
